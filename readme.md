# 📦 Sistema de Consulta de Endereço via CEP

Este é um projeto simples em PHP que permite buscar informações de endereço usando a API ViaCEP.  
O usuário informa um CEP, e o sistema retorna automaticamente dados como rua, bairro, cidade e estado.  
O projeto inclui validações, mensagens de carregamento, feedback visual e suporte a tema claro/escuro.

---

## 📚 Requisitos

Antes de executar o projeto, verifique se possui os seguintes requisitos instalados:

- **PHP 7.4+** (recomendado: PHP 8.0 ou superior)
- **Servidor embutido do PHP** ou ferramentas como:
  - Apache
  - Nginx
  - XAMPP / WAMP / Laragon
- Navegador atualizado (Chrome, Firefox, Edge etc.)
